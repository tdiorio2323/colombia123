# Project Overview

This is a production-ready full-stack React + Express starter project. It leverages Vite for a fast development experience, TailwindCSS for styling, Vitest for testing, and shared TypeScript types for a robust and maintainable codebase.

# Building and Running

The project uses `npm` scripts for various development tasks.

*   **Run app locally (Vite + Express):** `npm run dev`
*   **TypeScript validation:** `npm run typecheck`
*   **Run Vitest tests:** `npm test`

For a complete list of available scripts, refer to the `package.json` file.

# Development Conventions

Contribution guidelines and repository specifics are detailed in `AGENTS.md`.

Key directory paths:

*   **Client SPA:** `client/`
*   **Server API:** `server/` (endpoints under `/api/*`)
*   **Shared types:** `shared/`
